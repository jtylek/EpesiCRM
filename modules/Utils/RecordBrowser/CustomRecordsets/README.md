# Utils/RecordBrowser/CustomRecordsets

An admin tool for creating and managing ad-hoc RecordBrowser recordsets directly from the UI, without writing a module. It stores each custom recordset's table name, active/inactive state, and menu placement in `recordbrowser_custom_recordsets`, and provides an admin listing to activate/deactivate, edit, or open the generated recordset's own management screen.

Part of the **Epesi Core** package on the admin Setup screen.
