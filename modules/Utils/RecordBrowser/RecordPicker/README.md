# Utils/RecordBrowser/RecordPicker

A form-element widget for picking one or more RecordBrowser records inline, without leaving the current page. Given a recordset tab (or list of tabs), it renders a selectable list with optional filters, criteria callback, column set, and sort order, and can offer a recordset dropdown when multiple tabs are allowed. Has no schema of its own — install/uninstall are no-ops.

Part of the **Epesi Core** package on the admin Setup screen.
