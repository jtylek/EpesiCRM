# Tools/SessionKeeper

Keeps a logged-in Epesi session alive by periodically pinging the server from the browser, preventing the user from being logged out due to inactivity while the tab is left open. Carries no database schema of its own; install/uninstall are no-ops.

Part of the **Epesi Core** package on the admin Setup screen.
