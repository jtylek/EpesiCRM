# Tools/WhoIsOnline

Tracks and displays which users are currently logged into Epesi. It keeps a `tools_whoisonline_users` table mapping each active session name to the logged-in user, letting the applet show a live "who's online" list.

Part of the **Epesi Core** package on the admin Setup screen.
