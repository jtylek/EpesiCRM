# Base/StatusBar

The status bar shown at the bottom/edge of the application shell. It has no module dependencies
of its own beyond the default theme it installs, and other modules (e.g. `Base/Theme/Administrator`)
depend on it for status-bar related configuration.

Part of the **Epesi Core** package on the admin Setup screen.
