# Base/User/Administrator

The admin screen for managing user accounts, built on `Utils_GenericBrowser` and `Base_ActionBar`
on top of the `Base_User` and `Base_User_Login` modules. It's where administrators create,
edit, and deactivate user logins and their credentials.

Part of the **Epesi Core** package on the admin Setup screen.
