# Base/Cron

Provides Epesi's scheduled-task (cron) subsystem, letting modules register jobs that run on a schedule and
giving administrators an admin screen to review/manage them. It depends on the Admin module for its admin
section, RegionalSettings for schedule formatting, and Utils/GenericBrowser for the job listing UI.

Part of the **Epesi Core** package on the admin Setup screen.
