# Base/EssClient

Performs requests to the Epesi Services Servers (ESS) and handles installation registration against them,
acting as the client side of that integration. It depends on Admin and Menu for its admin/menu presence and
on QuickForm and Utils/FrontPage for the forms it presents, and is itself a prerequisite for EpesiStore.

Part of the **Epesi Core** package on the admin Setup screen.
