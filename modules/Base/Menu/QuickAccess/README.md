# Base/Menu/QuickAccess

Adds a quick-access shortcut list to the main menu (`Base_Menu`) so users can jump straight to
frequently-used modules without navigating the full menu tree. It depends on `Base_Menu` for the
menu it augments and on `Base_Acl` for permission checks on the shortcuts it offers.

Part of the **Epesi Core** package on the admin Setup screen.
