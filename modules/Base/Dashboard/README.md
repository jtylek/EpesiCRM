# Base/Dashboard

An iGoogle-style personalizable dashboard: users get their own tabs (`base_dashboard_tabs`) holding applets
(`base_dashboard_applets`) with per-applet settings (`base_dashboard_settings`), positioned in columns with a
color; system-wide default tabs/applets/settings ship as a starting layout for new users. On install it also
registers the "Dashboard" and "Dashboard - manage applets" permissions and sets Dashboard as a default home
page for employees.

Part of the **Epesi Core** package on the admin Setup screen.
