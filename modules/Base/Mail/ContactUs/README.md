# Base/Mail/ContactUs

Contributes a "Contact Us" entry to the Support menu group alongside About, EssClient, EpesiStore and Help,
using Base/Mail to send the message. It has no database schema of its own — install/uninstall only
(un)registers its default theme — and depends on the Theme and Menu modules.

Part of the **Epesi Core** package on the admin Setup screen.
