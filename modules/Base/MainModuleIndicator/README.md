# Base/MainModuleIndicator

Controls the browser page title and the "which module is active" indicator shown in the app
header. On install it seeds the `base_page_title`, `show_caption_in_title`, and
`show_module_indicator` variables plus the custom `logo_file`/`login_logo_file` paths used to
override the default branding logo and the login-screen logo.

Part of the **Epesi Core** package on the admin Setup screen.
