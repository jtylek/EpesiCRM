# Base/Help

Provides Epesi's interactive, in-context help — the per-screen help entries other modules register via
`$this->help(...)` and the help panel/toggle that displays them. It has no database schema of its own and
depends on Acl, Box and Theme/Administrator to render, alongside Setup and Tooltip.

Part of the **Epesi Core** package on the admin Setup screen.
