# Base/ActionBar

Renders the action bar component shown on module screens — the row of icon buttons (back, launcher/QuickAccess
shortcuts, module-contributed actions) sorted by position and icon order. It depends on the QuickAccess menu,
the Tooltip and Leightbox libraries, and per-user settings to build and display this bar consistently across
the app.

Part of the **Epesi Core** package on the admin Setup screen.
