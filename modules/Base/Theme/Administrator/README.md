# Base/Theme/Administrator

The admin screen for managing themes, built on top of `Base_Theme`, `Base_Admin`, and
`Base_StatusBar`. It lets administrators pick and configure the active theme rather than editing
the `default_theme` variable directly.

Part of the **Epesi Core** package on the admin Setup screen.
