# Base/About

Provides the "About Epesi" screen, reachable from the Support menu group alongside Help, EssClient and
EpesiStore. It has no database schema of its own — install/uninstall only (un)registers its default theme —
and depends on Lang, Tooltip and Leightbox for the info it displays.

Part of the **Epesi Core** package on the admin Setup screen.
