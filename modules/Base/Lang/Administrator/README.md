# Base/Lang/Administrator

The admin-facing side of translation management: it enables per-user language switching (`allow_lang_change`)
and tracks translation contributors and their credit preferences in `base_lang_trans_contrib` (name, whether
to show credits, credits website, contact email). It requires Admin, Acl, Theme, QuickForm, User and
Utils/GenericBrowser to provide its admin screens.

Part of the **Epesi Core** package on the admin Setup screen.
