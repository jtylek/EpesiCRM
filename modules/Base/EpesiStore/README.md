# Base/EpesiStore

Lets an administrator buy and download additional modules and updates from the Epesi Store, tracking
installed store modules and their licenses in the `epesi_store_modules` table (module id, version, license
id, file) plus a dedicated data directory for downloaded packages. It builds on Base/EssClient for the actual
server requests/registration.

Part of the **Epesi Core** package on the admin Setup screen.
