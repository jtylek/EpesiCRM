# Apps/Shoutbox

An internal chat applet for posting short messages to all employees or to a specific user. Messages (sender, optional recipient, text, posted-on timestamp, and a soft-delete flag) are stored in `apps_shoutbox_messages`. Adds the "Shoutbox" permission for employees and a separate "Shoutbox Admin" permission restricted to superadmins.

Part of the **Epesi Core** package on the admin Setup screen.
