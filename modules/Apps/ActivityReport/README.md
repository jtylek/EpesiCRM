# Apps/ActivityReport

Reports on user activity within Epesi (e.g. actions logged against CRM contacts), gated behind the "View Activity Report" permission for employees and managers. It also registers a RecordBrowser addon on the `contact` recordset (`contact_addon`) that surfaces a per-contact activity label directly on Contacts records.

Part of the **Epesi Core** package on the admin Setup screen.
