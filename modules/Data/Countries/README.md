# Data/Countries

Seeds reference geography data used throughout the app as CommonData trees: a `Calling_Codes` array of country dialing codes, a `Countries` list of country names, and nested subdivision lists for the US (states, plus Philadelphia-area PA counties), Poland, Romania, and Canada (provinces). All of it is stored via Utils/CommonData and removed again on uninstall.

Part of the **Epesi Core** package on the admin Setup screen.
