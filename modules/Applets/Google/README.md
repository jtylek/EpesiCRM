# Applets/Google

A small dashboard box showing the Google logo alongside a text field and Search button. Submitting a query opens a Google web search for that term in a new browser tab/window; the applet holds no state or configuration of its own.

Part of the **Epesi Core** package on the admin Setup screen, listed under its Optional
list as **Additional applets**.
