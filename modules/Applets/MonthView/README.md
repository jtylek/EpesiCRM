# Applets/MonthView

A compact monthly calendar box (a FullCalendar mini-embed) showing the current user's own CRM Calendar events. Clicking a day jumps into CRM Calendar's Day view for that date with the add-event flow already open, and a "jump to date" picker lets the user navigate to a different month.

Part of the **Epesi Core** package on the admin Setup screen, listed under its Optional
list as **Additional applets**.
