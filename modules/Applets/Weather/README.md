# Applets/Weather

A small dashboard box that shows current weather conditions pulled from a configurable weather RSS feed (feed URL, zip/location code, and temperature unit are all set per-instance). The feed is fetched asynchronously through `refresh.php` and automatically refreshes roughly every 30 minutes while the box is on screen.

Part of the **Epesi Core** package on the admin Setup screen, listed under its Optional
list as **Additional applets**.
