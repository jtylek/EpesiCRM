# Applets/Host

A small dashboard box with a text field where the user can enter either an IP address or a domain name. Submitting it performs a DNS lookup: an IP address is resolved to its hostname (reverse DNS), while a domain name is resolved to its IP address(es), and the result is printed back into the box.

Part of the **Epesi Core** package on the admin Setup screen, listed under its Optional
list as **Additional applets**.
