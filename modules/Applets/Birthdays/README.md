# Applets/Birthdays

A dashboard box listing contacts whose birthday falls within a configurable upcoming number of days, sorted by date, optionally restricted to only favorite contacts. Each row shows last name, first name and birth date via a RecordBrowser mini-view. It depends on CRM Contacts being installed with a "Birth Date" contact field — `simple_setup()` hides the applet from the Setup screen entirely if that field isn't present.

Part of the **Epesi Core** package on the admin Setup screen, listed under its Optional
list as **Additional applets**.
