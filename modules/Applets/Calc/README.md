# Applets/Calc

A small dashboard box with an on-screen four-function calculator: number and operator buttons (0-9, +, -, x, /, =, c) build up an expression in a text field, and pressing "=" evaluates it. It's a basic pocket-calculator widget with no memory, history, or configuration.

Part of the **Epesi Core** package on the admin Setup screen, listed under its Optional
list as **Additional applets**.
